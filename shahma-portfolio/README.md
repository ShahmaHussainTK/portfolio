# Shahma Hussain TK — Portfolio

A responsive React + Tailwind CSS portfolio starter.

## Run it on your laptop

1. Extract the ZIP file.
2. Open the extracted `shahma-portfolio` folder in VS Code.
3. Open Terminal in VS Code.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local address shown in the terminal (usually `http://localhost:5173`).

## Before publishing

- Replace `Add your professional email here` in `src/App.jsx` with your real email.
- Check each project description and technology list for accuracy.
- Add the E-Waste project's GitHub repository URL if it is public.
- Add a link to your live project demos if available.
- You can update your internship details if you want to show the company and dates.

## Build for deployment

```bash
npm run build
```

The production website will be created in the `dist` folder. You can deploy it using Vercel or Netlify.
